The Paradigm: Evaluative Decision Compute vs. Generative LLMs
Creative software is not bottlenecked by asset generation; it is bottlenecked by discrete decision latency. Deciding which layout template, transition curve, or B-roll bin to select via cloud LLMs introduces 1,500 ms round-trips, non-deterministic hallucinations, and runaway API bills. Zev replaces the LLM in the decision loop, evaluating candidate options at 60 fps directly on the local machine with 100% order invariance.

03 // Architectural Matrix: Zev vs. Cloud LLMs

Evaluation Dimension Cloud LLM (GPT-4o / Claude) Zev Engine (zev-rs) Production Impact
Inference Latency 600 ms – 2,500 ms 5 – 25 microseconds (p50: 5.8 µs) Permits 60 fps real-time timeline scrubbing & slider feedback
Operating Cost (10k ops) $5.00 – $25.00 per batch $0.00 (Zero API or token cost) Viable for automated high-volume rendering clusters
Offline / On-Set Usage Fails without active internet 100% On-Device / Air-Gapped Runs in on-set video village laptops with zero connectivity
Order Invariance Unstable (Permuting options flips choice) 100% Invariant (0.0% permutation flip) Guarantees deterministic, reproducible video rendering
Hallucination Risk Invented IDs or malformed JSON syntax 0% (Strictly bounded to provided schema) Prevents downstream automated rendering crashes
Host Integration Cloud REST API (requires API keys) WASM, C-ABI (.dylib/.dll), CLI, Local Daemon Embeds natively in Adobe CEP/UXP, Premiere, and Figma plugins
Deployment Recommendations for Creative Software
• Adobe Premiere Pro & After Effects (Desktop): Link against Zev via C-ABI dynamic library (.dylib / .dll) or run zev serve as a lightweight localhost daemon (http://127.0.0.1:8080).
• Figma & Webflow (Web / Canvas): Compile zev-rs to WebAssembly (wasm32-unknown-unknown) to run 100% in-browser without sending user creative data across the wire.
