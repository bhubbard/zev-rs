BEGINNER'S GUIDE // HOW ZERO-TOKEN DECISIONS WORK

Why is this different from ChatGPT or Llama? When you ask standard LLMs to classify a ticket, they generate text character-by-character (e.g. "I think this belongs to... Billing"). This wastes hundreds of milliseconds and can hallucinate.

Zev is a "System 1" engine: You give it a text snippet and a set of candidate choices. Instead of generating prose, Zev directly scores the probability distribution across your candidates in sub-millisecond CPU time. If you swap the order of choices, Zev’s mathematical order-invariance guarantees you get the exact same answer (0.0% flip rate).

ENGINE MODES & TIERS

The Four Zev Configurations Explained

Zev offers multiple execution tiers depending on your latency goals, hardware environment, and whether you want lightweight CPU heuristics or deeper neural tensor projections.

TIER 1 // FAST-PATH HEURISTICS

Zev-Default

The standard production engine: 100% pure Rust SIMD execution with zero-rescan token indexing, boundary-bounded token matching, and calibrated temperature scaling.

Latency (p50): 0.371 ms
Memory Footprint: 0 MB External Weights
JevBench Accuracy: 69.26% (160/231)
Execution Device: Pure CPU (AVX2/NEON)
Best For: Microservices, API Gateways

Pre-indexes premise byte offsets into an in-memory hash map during PremiseContext::new, evaluating bounded queries in $O(1)$ without repeated rescans.

TIER 2 // CONTRASTIVE HEAD

Zev-CLM

Contrastive Language Model (CLM) verifier fallback. Embeds state and candidate actions into unified vector representations to score candidate similarities.

Latency (p50): 0.406 ms
Memory Footprint: Lightweight Head
JevBench Accuracy: 67.53% (156/231)
Execution Device: CPU SIMD Dot-Product
Best For: Shortlist Disambiguation

Invoked when ZEV_FALLBACK=clm or when SIMD confidence is near the margin threshold. Directly computes contrastive scores without allocating heavy arena buffers.

TIER 3 // SPECULATIVE HYBRID

Zev-Apfel

The highest accuracy configuration: speculative hybrid cascading that runs SIMD first, escalating ambiguous edge cases to Apple Intelligence on-device FoundationModels.

Latency (p50): 0.469 ms
Memory Footprint: 0 MB Download (OS Model)
JevBench Accuracy: 70.13% (162/231) 🏆
Execution Device: Apple Silicon NPU
Best For: Nuanced Legal & Medical Text

Uses apfel-rs to tap directly into macOS 15's native 3B FoundationModel without downloading weights, boosting complex multi-step routing decisions.

TIER 4 // TENSOR MATMUL (PLANNED)

Zev-Candle

Cross-platform pure-Rust tensor execution using Hugging Face's Candle. Encodes candidate options into contiguous 2D tensors for single batched BLAS/Metal GEMM passes.

Latency (p50): ~7.8 ms
Memory Footprint: ~35 MB – 80 MB Tensors
Stress Test Accuracy: 100.0% (14/14 tests)
Execution Device: CPU (BLAS) / GPU (Metal/CUDA)
Best For: Linux, Docker, Cross-Platform

Bridges the gap on Linux/Docker servers where Apple FoundationModels aren't available, providing 100% accuracy on complex metaphors in single-digit milliseconds.

SYSTEM DESIGN

Architectural Principles

Engineered for extreme reliability, strict guardrails, and deterministic outcomes in high-throughput production environments.

01 // CANONICAL ISOLATION

0.0% Order Flip Rate

Isolated premise-option attention slots eliminate option order bias completely. Permuting candidate options produces 100% identical calibrated logits.

02 // SAFETY GUARDRAILS

Strict Abstention

Refuses to hallucinate when evidence is missing (__insufficient__) or when continuous estimates exceed calibrated bounds (out_of_range).

03 // MOMENT STATISTICS

Continuous Moments

For ordinal ratings and numeric rubrics, computes expected mean (∑ vi pi), variance, standard deviation, and quantiles (p10, p90).

04 // WIRE COMPATIBILITY

Multi-Protocol REST

Drop-in compatibility for native /v1/decisions, TypeSafe /v1/systemone, and Together AI /v1/tev1 schemas.

05 // ZERO-RESCAN INDEXING

Single-Pass Tokenizer

Pre-indexes byte positions into an in-memory token map in PremiseContext, evaluating bounded queries in $O(1)$ without repeated scans.

06 // HYBRID CASCADE

Speculative Fallback

Sub-millisecond SIMD runs first; automatically cascades to on-device Apple Intelligence (apfel-rs) or Candle BLAS tensors when uncertainty is detected.
