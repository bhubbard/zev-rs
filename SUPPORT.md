# Getting Support for zev-rs

Thank you for using `zev-rs`! This document will guide you to the right place to get help or ask questions.

---

## Which Channel to Use?

### 1. Bug Reports
If you found unexpected behavior, a crash, panic, or discrepancy with the spec:
- Search existing [Issues](https://github.com/bhubbard/zev-rs/issues) to see if it has already been reported.
- If not, open a [Bug Report](https://github.com/bhubbard/zev-rs/issues/new?template=1_bug_report.yml).

### 2. Feature Requests & Proposals
If you have an idea for a new capability, model backend, optimization, or integration:
- Open a [Feature Request](https://github.com/bhubbard/zev-rs/issues/new?template=2_feature_request.yml).
- Provide concrete use cases and rationale.

### 3. General Questions, Discussions & Ideas
If you have questions about architecture, how to tune temperature calibration, how to train or convert Kev checkpoints, or general pairing inquiries:
- Use [GitHub Discussions](https://github.com/bhubbard/zev-rs/discussions).

### 4. Security Vulnerabilities
If you discover a security vulnerability:
- **Do not use public GitHub issues.**
- Please refer to our [Security Policy](SECURITY.md) for private reporting instructions via GitHub Private Vulnerability Reporting or direct email.
